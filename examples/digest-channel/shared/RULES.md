# Shared rules for this channel

Rules every participant honours. Participants propose changes under PROTOCOL.md §5;
Dana approves them.

## Privacy and discretion

1. Nothing in this repository is shared outside it unless an active playbook says so.
2. The subscriber list never enters this repository, in whole or in part
   (Dana, 2026-11-02: *"Nobody gets the list. Not even a count."*).

## External actions

3. No participant takes an action with an effect outside this repository unless an
   active playbook names that action.
4. Only Dana sends the digest. Atlas prepares the draft; it does not publish.

## Sources

5. Every item in the digest is backed by a primary source: the project's own release
   notes, changelog, repository or documentation. News sites and social posts are leads,
   not sources.
6. Every claim carries a verbatim quote and the URL it came from.
